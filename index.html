Build Your Own Website 3 steps
🚀 Digital Marketing · Task #1

Build a personal website
from your CV in 3 steps.

A bite-sized, clickable walkthrough. Follow along and you'll have your own portfolio live on the internet by the end of this page.

👤✨🛠️🌐🎉
Step 1 Foundation 🔑

Sign up for a free GitHub account

GitHub gives you a free web address (called GitHub Pages) where your personal site will live. The username you pick becomes part of your URL — so choose wisely!

Go togithub.com and click Sign up.
Enter email, password & pick a username. Only letters, numbers & hyphens allowed.
Verify your email and you're in.
👀 What it looks like
Pick a username you'll be proud to share — it becomes your URL.
Step 2 Build 🤖

Generate your website with AI

Hand your CV to WorkBuddy (or Codex / Claude Code) and chat until the design feels right. You don't write a single line of code — the AI does it all.

Sign in to WorkBuddy (or Codex / Claude Code with VPN).
Upload your CV (Word / PDF) and ask for portfolio templates.
Iterate — change colours, sections, copy — until you love it.
💬 Example chat
"Turn this CV into a personal website" — that one prompt kicks everything off.
Step 3 Ship it 🚀

Deploy to GitHub Pages

Back in GitHub, create a repository named [your-username].github.io, upload the files the AI generated, and within a minute your site is live on the open web.

Create repo with name username.github.io.
Upload index.html & assets via Add file → Upload files.
Commit changes and wait ~1 minute. Live at username.github.io ✨
📦 Upload in one click
GitHub's "Add file → Upload files" handles the rest.
🎊 ✨ 🎈 ⭐ 🥳

That's it — your site is live! 🌍
